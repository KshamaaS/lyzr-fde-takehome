# Deploy

Three surfaces. The repo is the source of truth; the other two are views of it.

| Surface | What runs there | Why |
|---|---|---|
| **GitHub** | Everything | The graded artefact |
| **HF Spaces** | `app/streamlit_app.py` only | Free public URL, no auth friction for a reviewer |
| **Lyzr Studio** | Two hosted agents (policy Q&A, claims triage) | Proof the patterns ship *on the product*, not only alongside it |

---

## 1. GitHub

```bash
git init && git add . && git commit -m "Lyzr FDE take-home"
git remote add origin git@github.com:<you>/lyzr-fde-takehome.git
git push -u origin main
```

`data/agent.db` is gitignored — it is regenerated by `make demo`, so the repo
stays clean and every reviewer produces their own traces.

## 2. Hugging Face Space

Create a Space (SDK: **Streamlit**), then push the contents of `hf-space/`:

```bash
git clone https://huggingface.co/spaces/<you>/claims-control-plane
cp -r hf-space/* claims-control-plane/
cd claims-control-plane && git add . && git commit -m "control plane" && git push
```

The Space bundles a pre-seeded `agent.db` so the dashboard has data on first
load. `PROVIDER=mock` is set in `app.py`, so the Space costs nothing to run and
needs no secrets.

**If you prefer a live Space:** add `ANTHROPIC_API_KEY` (or `LYZR_API_KEY`) as a
Space secret and set `PROVIDER` accordingly. Not required for the demo.

## 3. Lyzr Agent Studio

Two agents, both defined in `lyzr/`:

```bash
export LYZR_API_KEY=...
python3 lyzr/setup_agents.py          # creates KB, uploads corpus, creates agents
```

This uploads `data/policy_docs/` into a Lyzr Knowledge Base and creates:

- **claims-policy-qa** — P2's pattern, native. KB-backed, citation instruction in the system prompt.
- **claims-triage** — P3's pattern as far as a hosted agent can express it.

Then run the repo against them:

```bash
PROVIDER=lyzr RETRIEVER=lyzr python3 p02_rag_citations/main.py --demo
```

**Free-tier note.** Community is 500 credits/month and LLM tokens bill
separately. Do not run `--all` or the golden-set evaluations against
`PROVIDER=lyzr` — a single 50-claim sweep across eight projects will exhaust the
month. Develop and evaluate on `mock`, and use the Lyzr path for demo runs and
the platform comparison only. This is the same discipline you would apply at a
customer with a credit budget, and it is why the provider seam exists.
